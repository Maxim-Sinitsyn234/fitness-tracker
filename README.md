# Fitness Tracker

Модуль фитнес-трекера на Go. Приложение разбирает данные о тренировках и дневной активности, рассчитывает дистанцию, среднюю скорость и потраченные калории и выводит отчёт.

## Возможности

- расчёт длины шага, дистанции и средней скорости;
- расчёт калорий для бега и ходьбы;
- парсинг строк с данными о тренировке и дневной прогулке;
- обработка некорректных строк без остановки программы;
- общий вывод информации через интерфейс для тренировок и прогулок.

## Структура проекта

```
cmd/tracker/          — точка входа
internal/actioninfo/  — интерфейс DataParser и общая функция вывода
internal/daysteps/    — дневная активность: парсинг и отчёт
internal/personaldata/— персональные данные пользователя
internal/spentenergy/ — расчёты дистанции, скорости и калорий
internal/trainings/   — тренировки: парсинг и отчёт
```

## Запуск

```bash
go run ./cmd/tracker
```

## Тесты

```bash
go test ./...
```

Подробный вывод:

```bash
go test -v ./...
```

## Формат данных

Дневная активность:

```
678,0h50m
```

Тренировка:

```
3456,Ходьба,3h00m
```

Первое значение — количество шагов, второе — длительность (для тренировки ещё и тип активности).
